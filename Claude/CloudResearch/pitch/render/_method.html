02 / 03

The method is a pipeline with four steps. First, detect the cloud with a trained spotter that combines a simple brightness rule, texture, and features from Meta's DINOv2 foundation model. Second, tell which date is cloudy: cloud lifts the darkest pixels in an image, while floods barely move them. Third, see through the cloud using the clear image as a reference: it tells us how dark the ground's darkest pixels should be, so we can estimate and remove the haze. Where the haze is too thick, below a transmission of 0.2, we do not invent ground. Fourth, decide road by road: assess, correct, or cannot assess. Then the flood detector, a random forest on classical, texture and DINOv2 change cues, makes the flood call. Example: tile 2_23_44, Imagery: Maxar via SpaceNet 8.
